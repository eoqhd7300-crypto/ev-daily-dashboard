📊 신차 스펙 트렌드

이미 수집된 신규 전기차 데이터를 발표월 기준으로 집계해, 핵심 스펙의 시간에 따른 변화 추이를 보여줍니다 (추가 API 호출 없이 기존 데이터만 재활용).

월별 집계 데이터

발표월 차량 수 배터리 용량 평균(kWh) 주행거리 평균(km) 최대충전출력 평균(kW) 최고출력 평균(kW)

⚠️ 데이터 한계 안내

  • Cell/Pack 에너지밀도는 실측(Teardown) 검증이 완료된 일부 차량에만 값이 있어(현재 전체의 10% 미만) 이번 버전의 트렌드 지표에서는 제외했습니다.
  • 0-100km/h 가속 시간은 약 44%의 차량에만 정보가 있어 신뢰도가 낮아 1차 버전에서는 제외했습니다.
  • 한 달에 수집된 차량 수가 적으면(예: 1~2대) 평균값이 시장 전체 추세를 대표하지 못할 수 있습니다 - 아래 표의 "차량 수"를 함께 확인하세요.
  • 모든 스펙 값은 Gemini가 생성한 데이터를 텍스트 패턴으로 추출한 것으로, 원본 발표 자료의 정확한 수치와 다를 수 있습니다.
